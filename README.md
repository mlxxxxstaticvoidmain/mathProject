# Численные методы

Настольное приложение с конспектами: Markdown, формулы KaTeX и интерактивные графики.
Работает офлайн, конспекты хранятся обычными файлами `.md` в папке «Документы/Численные методы».

## Быстрый старт

```bash
npm install
npm start        # запуск
npm run dev      # запуск с инструментами разработчика
```

## Как писать конспект

Есть три способа, от простого к сложному.

### 1. Конструктор (ничего не нужно помнить)

Кнопка **«Конструктор»** на панели инструментов или `Ctrl+Shift+B`.

- «Формулы» — выберите «Дробь», «Корень», «Интеграл», «Матрица» и т. п.;
- заполните подписанные поля (числитель, знаменатель, пределы…);
- внизу сразу виден результат — нажмите «Вставить блоком».

Там же есть вкладки **«График»** и **«Таблица»**: заполните поля, посмотрите
предпросмотр и вставьте готовый блок.

### 2. Палитра и кнопки

- **«Палитра»** (`Ctrl+Shift+K`) — готовые формулы в один клик, включая методы
  (Ньютон, бисекция, Симпсон, Гаусс — Зейдель и другие).
- Кнопки на панели: жирный, курсив, заголовок, таблица, степень, индекс, корень, дробь, сумма, интеграл.
- Если курсор вне формулы, знаки `$` добавятся сами.

### 3. Вручную

- Формула в строке: `$x_i^{2}$`.
- Формула отдельной строкой:

  ```text
  $$
  x_{k+1} = x_k - \frac{f(x_k)}{f'(x_k)}
  $$
  ```

- Блок кода с языком `plot` превращается в интерактивный график:

  ````text
  ```plot
  f(x) = x^3 - 2x - 5
  g(x) = 3x^2 - 2
  x: -3..3
  y: -8..8
  title: Функция и производная
  ```
  ````

- Таблица — обычный Markdown: `| a | b |` и строка `| --- | --- |`.
- Полная шпаргалка — `F1`.

## Калькулятор

Кнопка **«Калькулятор»** (`Ctrl+Shift+C`).

- Операции: `+ − * / ^ %`, скобки, неявное умножение (`2(3+1)`).
- Функции: `sin, cos, tan, cot, asin, acos, atan, sinh, cosh, tanh, exp, ln, log, log2, sqrt, cbrt, abs, sign, floor, ceil, round, min, max, pow, mod`.
- Константы: `pi`, `e`, `tau`.
- Дробная часть — через точку: `1.5`.
- «Вставить ответ» переносит результат в конспект, история вычислений сохраняется.

## Горячие клавиши

| Клавиши | Действие |
| --- | --- |
| `Ctrl+N` | новый конспект |
| `Ctrl+S` | сохранить сейчас |
| `Ctrl+E` | экспорт в PDF |
| `Ctrl+M` | формула в строке |
| `Ctrl+Shift+M` | формула отдельной строкой |
| `Ctrl+Shift+P` | график |
| `Ctrl+Shift+K` | палитра формул |
| `Ctrl+Shift+B` | конструктор записи |
| `Ctrl+Shift+C` | калькулятор |
| `Ctrl+F` | поиск в тексте конспекта |
| `Ctrl+1 / 2 / 3` | редактор / пополам / чтение |
| `Ctrl+Shift+L` | светлая / тёмная тема |
| `F1` | шпаргалка |

## Сборка

```bash
npm run dist       # установщик и portable-версия в dist/
npm run dist:dir   # только распакованная сборка
```

Конфигурация сборки — в `package.json` (`build`). Подписи кода нет; при необходимости
добавьте сертификат в настройки electron-builder. Если нужна своя иконка, положите
`build/icon.ico` (Windows) или `build/icon.png` (512×512) — electron-builder подхватит её
автоматически. Сейчас используется стандартная иконка Electron.

## Обновление библиотек

KaTeX, marked и DOMPurify подключены из `app/vendor/`, поэтому приложение не зависит
от `node_modules` во время работы. Обновить их можно так:

```bash
npm update katex marked dompurify
npm run sync-vendor
```

## Структура

| Путь | Назначение |
| --- | --- |
| `main.js` | главный процесс Electron: окно, меню, файлы, PDF |
| `preload.js` | безопасный мост `window.api` |
| `app/index.html` | разметка интерфейса |
| `app/styles.css` | оформление |
| `app/renderer.js` | редактор, предпросмотр, конструктор, калькулятор |
| `app/plot.js` | парсер выражений и интерактивные графики |
| `app/starter.md` | стартовый конспект при первом запуске |
| `app/vendor/` | KaTeX, marked, DOMPurify и шрифты |
| `scripts/sync-vendor.js` | копирование библиотек из `node_modules` |

## Служебное

Smoke-проверка (создаёт временные скриншоты и PDF в корне проекта):

```powershell
$env:NN_SMOKE='1'; $env:NN_NOTES_DIR="$env:TEMP\nn-smoke"; npm start
```

Папку с конспектами можно переопределить переменной `NN_NOTES_DIR`.
